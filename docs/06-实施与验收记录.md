## 1. 实现范围

### 1.1 已实现

- 应用壳：左侧导航（发现/我的音乐，无“系统”分栏）、顶部搜索/刷新/主题/全屏、右上角设置齿轮、底部播放条、全屏正在播放、移动端底部导航。
- 导航：独立“关于”页已移除，合并到设置 → 关于；`#/about` 兼容跳转到设置 About。
- 首页：当前/上次专辑 Hero、格式徽章、播放/暂停、专辑网格。
- 专辑：网格、搜索过滤、专辑详情、曲目列表（含 `SongsLen` 时长）、播放全部/单曲、当前曲目高亮。
- 艺术家：按 `AuthorList` 聚合、艺术家详情。
- 网络电台：点击左侧入口直接进入，离开自动退出；分类/电台/收藏/添加删除；电台数据使用独立 `radioAlbums`/`radioSongs`，不混入本地专辑。
- 播放列表：只显示 `aplayer.dat` 与 `.ap2` 保存列表；不展示文件系统目录。文件浏览独立保留 `Drives` 树。
- 设置：右上角齿轮入口；左侧无“系统/关于”；7 个主分页 + 常规 5 个子标签 + Decoder/DSP 子分页；参数中文化；底部单一操作行（导出/导入/保存），导入导出覆盖完整配置。
- 播放控制：播放/暂停/停止/上一首/下一首/进度（百分比）/音量（启用时显示）、1s 轮询、页面隐藏降频、离线退避。
- 当前播放队列：播放栏右侧按钮打开底部弹窗；按专辑分组，当前专辑/曲目高亮，按需载入其他专辑曲目；支持保存为 aplayer 播放列表、取消、Esc 关闭；重绘保持滚动位置与焦点。
- 首页曲库：初始化及回到首页时始终按 `root_folder` 载入根目录，不再把上一次当前播放列表当作首页；`.137` 实测 45 张专辑。
- 安全：所有 aplayer 字符串经 `htmlToText`/`textContent`；URL 协议白名单；不显示 `api_key`/`api_cx`；危险操作二次确认。
- 构建：单 JS + 单 CSS；无 SVG/字体/WebP/`.mjs`/sourcemap；静态白名单检查；热替换安装/回滚脚本。

## 5. 关键实现说明

### 5.1 库自动载入

```
init()
  GET GetConfig
  GET State
  if RadioMode:
    GET GetAlbums        // 电台分类
  else:
    GET GetAlbums
    if root_folder 非空:
      GET GetPlaylists(-1)
      在 Drives 中匹配 root_folder（level 0）
      GET GetPlaylist(index)
      GET GetAlbums      // 根目录曲库
回到首页（#/home）且非电台模式：
  ensureLibrary(false)   // 若当前不是根目录则重新载入根目录
```

- `root_folder` 为空时不自动载入任意 `/` 目录，避免误把系统目录当媒体库。
- 首页展示根目录曲库，不沿用上一次“当前播放列表”；打开某张专辑/播放列表后返回首页会重新载入根目录。
- 当前播放队列只显示当前播放专辑；打开时只加载该专辑曲目，不再列出曲库中的其他专辑。
- `GetPlaylists&ind=N` 是展开/折叠切换；UI 用 `Drives[].expanded === 1` 显示“折叠/展开”。

### 5.2 配置安全

- `SetConfig` 整包覆盖；UI 先 `GetConfig`，用 `WRITABLE_FIELDS` 合并后再 POST。
- 保存后再次 `GetConfig`，比对 `covers/root_folder/volume_enabled/dop_mode/pframes`。
- 失败/不一致 Toast；支持 JSON 导出/导入；安装脚本备份 `config.dat`。
- 已知：aplayer 会话后可能回写 `config.dat`（触发点未完全隔离），运维层仍需备份。

### 5.3 安全

- `htmlToText` + `textContent` 处理所有 aplayer 字符串；`Playlists`/`conv_list` 不直接 `innerHTML`。
- 电台 URL/图片 URL 只允许 http/https。
- 不显示/不导出 `api_key`/`api_cx`。
- 仅可信 LAN；无登录，与 aplayer 原生边界一致。

### 5.4 刷新不中断播放（0.2.13）

- 现象：播放中刷新浏览器，aplayer 停止播放。
- 根因：页面初始化调用 `ensureLibrary(true)` → `GetPlaylist(root)`；aplayer 的 `GetPlaylist` 会切换当前播放列表并停止播放。
- 修复：`ensureLibrary` 在 `Playing`/`Paused` 时直接返回，不调用 `GetPlaylists`/`GetPlaylist`；初始化先写入 `player` 状态，保证守卫能读到。
- 延迟恢复：播放期间首页仍显示当前播放列表；页面记录 `deferredLibraryReload`，等播放停止且仍在首页时再载入根目录，不打断播放。
- 验证：`.133` 播放中刷新，请求列表无 `GetPlaylist`/`GetPlaylists`，`Playing` 保持 true；停止后才出现根目录加载请求。`.137` 已部署 0.2.13 并完成版本/静态冒烟；现场播放未主动起停。

### 5.5 按原版逻辑切换曲目（0.2.15）

- `.205` 原版 `/d` 的 `PlayCommand2()`：若当前正在播放/暂停，先 `StopCommand(ParseStopPlay)`，在 Stop 回调里再 `PlayCommand()`；`PlayCommand()` 在 `Playing` 为 true 时直接返回。
- APUI 0.2.15 按同样顺序：`play()` 在 `Playing`/`Paused` 时先 `?Stop`，成功后 `?Play&album=&song=`；不再做暂停后补 Pause，也不做额外的 Play 结果重试。
- 验证 `.133`：暂停状态选专辑，请求序列 `Stop → Play`，新曲目开始；`.137`：播放中打开 Force Field 播放全部，序列 `Stop → Play&album=3`，`PlayingName` 切为 `Bridge Of Dreams`。
