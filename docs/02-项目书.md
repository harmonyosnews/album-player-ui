## 1. 项目概述

### 1.1 背景

Album Player for Linux（aplayer）2.19 是闭源免费播放器，音频路径以低资源、低干扰为目标，支持 ALSA/Diretta、PCM/DSD、网络电台、播放列表等。它的 Web 遥控界面仍以传统表格、图片按钮和 Zepto 脚本为主，视觉与交互明显落后于同环境中的 TinyLMS 1.3.4。

TinyLMS 的界面是成熟的现代 SPA：深色主题、暖金色强调色、左侧导航、卡片式专辑、底部常驻播放条、全屏正在播放、移动端底部导航。用户希望 aplayer 也拥有同等水准的操作界面，同时不改变其音频链路。

### 1.2 项目目标

1. **体验目标**：用新 UI 替代 aplayer 旧 Web 界面，视觉/交互达到 TinyLMS 水准；桌面、平板、手机均可顺畅操作。
2. **功能目标**：覆盖 aplayer 的核心听音操作（专辑、曲目、播放控制、进度、音量、电台、播放列表、常用设置）。
3. **交付目标**：一份静态产物同时适用于 ARM64/x86_64；安装/卸载/回滚简单；不新增系统服务、端口、init 适配。
4. **安全目标**：不引入 XSS；配置写入可回滚；不扩大现有攻击面；敏感字段不外显。
5. **维护目标**：源码、构建、接口、部署、验收文档齐全；aplayer 升级后可快速适配/回滚。

### 1.3 项目范围

**包含：**

- 新前端的设计、开发、测试、构建、打包、部署脚本。
- aplayer 2.19 原生 HTTP 接口的适配层（同源查询串）。
- 页面：首页/正在播放、专辑、艺术家、文件浏览（受控）、网络电台、播放列表、当前播放队列（只读）、设置（含关于/诊断）。
- 响应式、深色/浅色主题、键盘操作、基础无障碍。
- `.133` 构建/冒烟，`.137` 实机播放/DSD/电台/配置验收。
- 文档：可行性、实施方案、项目书、开发手册、接口文档、验收报告。

**不包含：**

- aplayer 二进制/音频引擎/ALSA/Diretta/DSD 修改。
- 播放队列编辑、历史、歌曲/专辑收藏、歌词、标签编辑、智能推荐、多房间。
- 7779 UPnP 渲染器界面。
- 伴生 Go 适配服务（二期可选）。
- 在 `.133` 做真实听感/声卡/DSD 验收。
- 法务/商标/再分发许可的最终意见（需另行确认）。

### 1.4 项目假设

- aplayer 2.19 的接口在项目周期内不变；变更时走变更流程。
- `.230`/`.137` 的 aplayer 工作目录均为 `/opt/aplayer`；若 `.137` 不同，部署脚本按实际 cwd 调整。
- `.133` 可在 Phase 0 安装 x86_64 aplayer 2.19；虚拟声卡只适合基础 PCM 冒烟，不影响 UI 构建，但不作为真机/DSD 验收。
- 用户接受“可信 LAN、无登录”的 MVP 安全边界；远程访问/鉴权列入二期。
- TinyLMS 仅作为视觉/交互参考，不直接复制其源码/资产；必要时法务确认。

### 1.5 关键约束

| 约束 | 影响 |
|---|---|
| aplayer 接口无官方文档、无 CORS、`OPTIONS` 501 | 必须同源部署；接口契约需 fixtures 固化 |
| `SetConfig` 整包覆盖 | 只能提交完整可写字段；必须备份/校验 |
| aplayer 会话可能回写 `config.dat`（实测 668→900 B，触发点未完全隔离） | 测试/部署要备份；避免频繁重启 |
| 静态资源白名单 | 只能产出 html/js/css/json/png；图标内联、系统字体 |
| `.133` 分析时缺 `/opt/aplayer`、仅虚拟声卡 | Phase 0 已修复（安装 x86_64 + APUI）；真实测试在 `.137` |
| `.137` 无 systemd | 不新增系统服务；原位替换 |
| `.230` 磁盘仅 901 MB | 构建在 `.133`；只部署小体积静态产物 |

### 2.3 关键场景

1. **晚间听专辑**：手机打开首页 → 点专辑 → 播放 → 锁屏/切后台 → 回到页面继续控制。
2. **电台**：进入网络电台 → 选分类 → 播放 → 收藏 → 查看当前曲目/图片。
3. **多格式**：播放 FLAC/DSD 文件 → 播放条显示 kHz/bit/ch/kbps；DSD 模式在设置中可见。
4. **切换输出**：设置 → 输出 → 选择声卡 → 二次确认 → 播放停止 → 新卡生效。
5. **故障恢复**：aplayer 退出/断网 → 页面提示离线 → 运维重启 → 页面自动恢复。
6. **升级/回滚**：厂商升级覆盖 UI → 重跑安装脚本 → 冒烟；异常 → 卸载脚本恢复旧界面。

## 3. 需求规格

### 3.1 功能需求

#### FR-01 应用壳与导航

- 左侧导航：发现（首页、专辑、艺术家、文件浏览）、我的音乐（网络电台、播放列表）；不设“系统”分栏。
- 顶部：设置齿轮（进入设置）、搜索、刷新、主题切换、全屏。
- 独立“关于”页已取消，合并到设置 → 关于；`#/about` 兼容跳转。
- 底部：播放条（封面、标题/艺术家、格式、上一首/播放暂停/下一首、播放队列、进度、时间、音量）。
- 移动端：底部 4 项导航；播放条紧凑；点击封面/标题打开全屏正在播放。
- Hash 路由；刷新不 404。

#### FR-02 首页/正在播放

- Hero：当前/上次专辑封面、专辑名、艺术家、年份、格式徽章（kHz/bit/ch/kbps）、播放/暂停。
- 无播放时：引导选择专辑；首页“全部专辑”展示根目录曲库的全部专辑。
- 播放栏：播放/暂停右侧提供“当前播放队列”，按专辑展开曲目，可保存为 aplayer 播放列表。
- 网络电台模式：Hero 显示电台名/当前曲目/图片。
- 全屏正在播放：大封面、模糊背景、标题/艺术家/专辑、进度、控制、关闭。

#### FR-03 专辑

- 网格/列表切换；按名称/艺术家/年份排序；按艺术家/年份过滤。
- 专辑卡：封面、名称、艺术家、年份；悬停显示播放按钮。
- 专辑详情：封面、元数据、曲目列表、播放全部、当前曲目高亮。
- 曲目点击播放；双击/单击行为需一致（移动端单击）。
- 封面：`GetImage`；失败占位；懒加载。

#### FR-04 艺术家

- 按 `AuthorList` 聚合；显示艺术家名、专辑数。
- 艺术家详情：专辑网格；点击进入专辑。
- 无艺术家图片：首字母/渐变占位（不请求外部）。

#### FR-05 文件浏览（受控）

- 默认仅显示 `GetConfig.root_folder` 下的内容；未配置时显示提示，不显示 `/`。
- 面包屑、返回上级、目录/文件图标、扩展名/大小（如可得）。
- 点击目录进入；点击音频/播放列表加载/播放。
- 风险提示：aplayer 原生接口可浏览文件系统；本页只做受控展示。
- 不提供删除/重命名/上传。

#### FR-06 网络电台

- 进入电台模式（`?RadioMode`）；分类列表（`GetAlbums`/`GetSongs`）。
- 电台列表：名称、分类、播放；收藏（`?Favor`）。
- 正在播放：`GetRadio.RadioTitle`；图片轮播 `GetPictures.Pics`。
- 添加：名称、URL、分类；URL 仅 http/https；`POST ?AddStation`。
- 删除：二次确认；`?DeleteStation`。
- 目录更新：Update/Replace；二次确认；提示备份 `Radio/`。
- 退出电台模式恢复专辑库。

#### FR-07 播放列表

- 列表：`GetPlaylists`；区分“最近列表/用户列表/目录”。
- 加载：`?GetPlaylist&playlist=N`；成功提示；曲目更新。
- 保存当前：输入名称；`?SavePlaylist&name=`；名称校验/去重提示。
- 删除：二次确认；`?DeletePlaylist&name=`。
- 说明：播放列表页只显示 aplayer 保存的 `aplayer.dat`/`.ap2`；文件系统目录在独立的“文件浏览”页，不混入播放列表。

#### FR-08 设置

- Tab：General、Decoder（DSD / DVD-A / Radio）、DSP（Converter / Resampler / Convolver）、System、Status、Card、About。
- 字段覆盖 `GetConfig` 可写项；只读状态不提交。
- 校验：数值范围、枚举、必填、URL。
- 保存：完整配置合并 → POST → 校验；失败回滚提示。
- 导出/导入 JSON；上一版保存在 localStorage。
- `SelectCard` 二次确认，提示中断播放。
- 危险项（DSP/卷积/颜色）默认折叠。

#### FR-09 搜索

- 顶栏输入；防抖 150ms；搜索专辑/艺术家/已加载曲目。
- 结果分组；点击跳转/播放；空结果提示。
- 不做服务端搜索；大库时按需加载曲目索引。

#### FR-10 状态与错误

- 在线/离线横幅；最后错误 `LastError`；扫描中 `Scanning` 指示。
- API 超时/404/JSON 错误/业务错误分类提示。
- 命令按钮请求中禁用；失败 Toast；不自动重试命令。
- 离线退避重连；恢复后刷新。

#### FR-11 安装/运维

- `install.sh` 备份厂商 UI + `config.dat`，安装 `aplayer.html` + `ui/`。
- `uninstall.sh` 恢复备份。
- `check-dist` 白名单/体积检查。
- 版本文件/校验和；README。

## 4. 现状与差距

- `.230` 有完整 aplayer 2.19（ARM64），但服务未启用；旧 UI 可用。

- `.137` 有 x86_64 aplayer 2.19，适合实机验收；无 systemd。
- TinyLMS 1.3.4 提供成熟 UI 参考，但后端能力与 aplayer 不同。

| 维度 | 现状 | 目标 | 差距/动作 |

| 部署 | 厂商文件 | 可安装/回滚的 UI 包 | 新脚本 |
| 测试 | 无 | 单测/契约/E2E/实机 | 新测试体系 |

## 5. 技术方案摘要

> 详细设计见 [01-实施方案.md](01-实施方案.md) 与 [03-开发手册.md](03-开发手册.md)。

### 5.1 架构

- **原位静态 UI 替换**：新 SPA 构建为 `aplayer.html` + `ui/app-<hash>.js/css`，放入 `/opt/aplayer`，由 aplayer 7778 同源提供。
- 无新增服务/端口；直接调用 aplayer 查询串 API。
- 前端：TypeScript + Vite + 原生模块/CSS；hash 路由；无框架运行时。
- 图标内联 SVG；系统字体；封面走 `GetImage`；静态图仅 PNG。
- 轮询 `?State` 1s；页面隐藏降频；命令后立即刷新。
- 配置写入：完整可写字段合并 + 校验 + 导出/导入 + 保存后校验。
- 安全：所有 aplayer 字符串消毒；禁止不可信 `innerHTML`；URL 协议白名单。

### 5.2 页面清单

| 路由 | 页面 | 数据源 | 关键操作 |
|---|---|---|---|
| `#/home` | 首页/正在播放 | `State`、`GetAlbums`、`GetImage` | 播放/暂停、打开专辑 |
| `#/albums` | 专辑库 | `GetAlbums` | 网格/列表、筛选、播放 |
| `#/albums/:index` | 专辑详情 | `GetSongs`、`GetImage` | 播放全部/单曲 |
| `#/artists` | 艺术家 | `GetAlbums.AuthorList` | 进入艺术家 |
| `#/artists/:name` | 艺术家详情 | `GetAlbums` 过滤 | 播放专辑 |

### 5.5 设计语言

- 深色默认；暖金 `#d4a574`；背景 `#0a0a0a/#141414/#1e1e1e`；文字 `#fff/#b8b8b8`。
- 卡片圆角 12–16px；阴影三档；边框 6% 白。
- 字体：系统 UI + 中文黑体；标题 24–32px；正文 14–16px。
- 过渡 150/250ms；`prefers-reduced-motion` 降级。
- 图标：内联 SVG，线性风格；不使用图标字体。
- 空状态/骨架/Toast/模态统一组件。

### 5.6 与 TinyLMS 的差异（有意为之）

| TinyLMS | APUI | 原因 |
|---|---|---|
| 队列编辑/历史/收藏/标签/歌词 | 不做 | aplayer 无对应接口 |
| 队列查看/保存 | 只读“当前播放队列” | 由 `GetAlbums` 当前播放列表实现，不能重排 |
| 智能电台/推荐 | 不做 | 无后端能力 |
| 多 Diretta Target/UPnP 设置 | 不做 | 属 7779/其他组件 |
| 媒体库扫描 | 不做 | aplayer 自动扫描/根目录配置 |
| SSE `/api/events` | 1s 轮询 | 同源静态方案无服务端；与厂商 UI 一致 |
| 独立 Go 服务 | 静态文件 | 跨 init、低资源、同源 |
