### 1.3 在 `.133` 安装 x86_64 aplayer（Phase 0）

`.133` 当前没有 `/opt/aplayer`，只有服务单元。开发前必须修复。推荐从 `.137` 复制同版本 2.19：

```bash
# 在本地工作站执行（两台机器之间不直连时）
ssh root@REAL-TEST-HOST 'tar -C /opt -czf - aplayer' > /tmp/aplayer-x64.tgz
scp /tmp/aplayer-x64.tgz root@X86-BUILD-VM:/tmp/

# 在 .133 执行
mkdir -p /opt
tar -C /opt -xzf /tmp/aplayer-x64.tgz
chown -R root:root /opt/aplayer
chmod 755 /opt/aplayer
chmod 755 /opt/aplayer/aplayer
ls -l /opt/aplayer/aplayer
file /opt/aplayer/aplayer   # ELF 64-bit x86-64
```

或者从官方下载 `aplayer64.tar.gz`（2.19），解压到 `/opt/aplayer`。无论哪种方式：

1. **备份原始** `config.dat`/`aplayer.log`（如果存在）。
2. 不要覆盖 `.137` 的配置；`.133` 用一份测试配置即可。
3. 运行前确认 7778 空闲：`ss -lntp | grep 7778`。
4. 启动：`cd /opt/aplayer && ./aplayer`；aplayer 会 fork 并监听 7778。
5. 验证：

```bash
curl -fsS http://127.0.0.1:7778/ | head
curl -fsS 'http://127.0.0.1:7778/?GetConfig' | head -20
curl -fsS 'http://127.0.0.1:7778/?State'
```

6. 停止：`curl -sS http://127.0.0.1:7778/stop`。

**重要：**

- `.133` 是虚拟机，只有 Ensoniq AudioPCI 虚拟声卡（基础 PCM），不满足真机/DSD 验收。执行 `Play`/`SetVolume`/`SelectCard` 等可能触发 PCM 打开；若 PCM 不可用，aplayer 会记录 `unable to open pcm device` 并退出 [E11]。UI 开发优先只用 `GetConfig`/`GetAlbums`/`State`，不要依赖 `.133` 的播放成功。
- 实测一次包含启动/查询/停止/音量的会话后，`config.dat` 会从 668 B 变为 900 B；触发点未完全隔离（可能是启动/退出、`Stop`/`SetVolume` 或配置保存）。按最保守假设：每次启动前备份，退出后恢复：

```bash
cp -a /opt/aplayer/config.dat /opt/aplayer/config.dat.bak
# ... 测试 ...
curl -sS http://127.0.0.1:7778/stop
cp -a /opt/aplayer/config.dat.bak /opt/aplayer/config.dat
```

- 不要同时运行多个 aplayer 实例。

```ts
      },
    },
  },
  // ... build 配置见 §4
});
```

`GET /ap/?GetAlbums` → `http://127.0.0.1:7778/?GetAlbums`。

```ts
// src/api/client.ts
const API_BASE = import.meta.env.DEV ? '/ap' : '';
```

生产构建后 `API_BASE = ''`，同源直接访问 `/?...`。

### 2.3 没有 aplayer 时：mock

需要可控状态/避免真实音频依赖时，推荐用 mock 联调 UI（Phase 0 实现）：

```
tools/mock_aplayer.py --port 7778 --fixtures tests/fixtures
```

mock 需要实现的端点（至少）：

- `GET /` → 返回 `aplayer.html`（或简单占位）
- `GET /?GetConfig` → 完整配置 fixture
- `GET /?GetAlbums` → 专辑/艺术家/年份/曲目 fixture
- `GET /?GetSongs&album=N` → 曲目
- `GET /?State` → 可随时间变化的状态（playing/paused/position）
- `GET /?GetPlaylists&ind=N` → 列表/Drives
- `GET /?GetRadio`、`/?GetPictures`
- `GET /?Play`、`/?Pause`、`/?Stop`、`/?Next`、`/?Prev`、`/?Position`、`/?SetVolume`
- `POST /SetConfig` → 校验并返回 `Settings saved!`
- `GET /stop` → 退出/停止 mock

mock 的行为要与 [04-程序接口文档.md](04-程序接口文档.md) 的契约一致；不要用 mock 的“理想响应”掩盖真实 aplayer 的怪癖（重复 Content-Type、HTML 404、整包配置）。

## 4. 构建与静态资源约束

### 4.1 硬约束

aplayer 只提供特定扩展名 [E5]：

```
允许：.html .js .css .json .png（+ 既有 UI 用到的图片类型）
禁止：.svg .woff .woff2 .ttf .webp .mjs .map .txt
```

因此：

- 单 JS + 单 CSS；关闭 code splitting；关闭 sourcemap。
- 图标用内联 SVG 字符串/data URI，不产出 `.svg` 文件。
- 字体用系统字体；不要 `@font-face` 指向 `.woff2`。
- 图片用 PNG 或 CSS 渐变；不要 WebP/SVG 文件。
- 入口最终命名 `aplayer.html`；资源放 `ui/`。
- 构建后必须跑白名单检查。

### 4.2 Vite 配置示例

```ts
// vite.config.ts
import { defineConfig } from 'vite';

export default defineConfig({
  base: '/',
  build: {
    target: 'es2020',
    outDir: 'dist',
    sourcemap: false,
    cssCodeSplit: false,
    assetsInlineLimit: 100_000_000, // 尽量内联，避免意外产物
    rollupOptions: {
      output: {
        inlineDynamicImports: true,
        entryFileNames: 'ui/app-[hash].js',
        chunkFileNames: 'ui/chunk-[hash].js',
        assetFileNames: (info) => {
          const name = info.name || '';
          if (name.endsWith('.css')) return 'ui/app-[hash][extname]';
          return 'ui/[name]-[hash][extname]';
        },
      },
    },
  },
  server: {
    host: '0.0.0.0',
    port: 5173,
    proxy: {
      '/ap': {
        target: 'http://127.0.0.1:7778',
        changeOrigin: false,
        rewrite: (p) => p.replace(/^\/ap/, ''),
      },
    },
  },
});
```

> 注意：`inlineDynamicImports` 与多入口不兼容；本项目单入口。若 Vite 版本对 `assetFileNames` 回调签名不同，按当前版本调整。

### 4.4 构建后检查脚本

```js
// scripts/check-dist.mjs
import { readdirSync, statSync } from 'node:fs';
import { join, extname } from 'node:path';

const ALLOWED = new Set(['.html', '.js', '.css', '.json', '.png', '.jpg', '.jpeg', '.gif', '.ico']);
const MAX_JS = 300 * 1024;
const MAX_CSS = 80 * 1024;

let bad = [];
let js = 0, css = 0;
function walk(dir) {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    const st = statSync(p);
    if (st.isDirectory()) walk(p);
    else {
      const ext = extname(name).toLowerCase();
      if (!ALLOWED.has(ext)) bad.push(`${p} (${ext})`);
      if (ext === '.js') js += st.size;
      if (ext === '.css') css += st.size;
    }
  }
}
walk('dist');

if (bad.length) {
  console.error('禁止的静态资源扩展名:\n' + bad.join('\n'));
  process.exit(1);
}
if (!statSync('dist/aplayer.html', { throwIfNoEntry: false })) {
  console.error('缺少 dist/aplayer.html');
  process.exit(1);
}
if (statSync('dist/index.html', { throwIfNoEntry: false })) {
  console.error('dist/index.html 应重命名为 aplayer.html');
  process.exit(1);
}
if (js > MAX_JS) console.warn(`JS 体积偏大: ${(js/1024).toFixed(1)} KB`);
if (css > MAX_CSS) console.warn(`CSS 体积偏大: ${(css/1024).toFixed(1)} KB`);
console.log(`dist OK: js=${(js/1024).toFixed(1)}KB css=${(css/1024).toFixed(1)}KB`);
```

### 5.2 请求封装

```ts
// src/api/client.ts
export class ApiError extends Error {
  constructor(public code: string, message: string, public status?: number) {
    super(message);
  }
}

const API_BASE = import.meta.env.DEV ? '/ap' : '';
let chain: Promise<unknown> = Promise.resolve();

function serialize<T>(fn: () => Promise<T>): Promise<T> {
  const next = chain.then(fn, fn);
  chain = next.catch(() => undefined);
  return next;
}

async function raw<T>(query: string, init?: RequestInit): Promise<T> {
  return serialize(async () => {
    let res: Response;
    try {
      res = await fetch(`${API_BASE}/?${query}`, {
        cache: 'no-store',
        signal: AbortSignal.timeout(5000),
        ...init,
      });
    } catch (e) {
      throw new ApiError('NETWORK', '无法连接播放器', undefined);
    }
    const text = await res.text();
    if (res.status === 404) throw new ApiError('NOT_FOUND', text, 404);
    if (!res.ok) throw new ApiError(`HTTP_${res.status}`, text, res.status);
    try {
      return JSON.parse(text) as T;
    } catch {
      throw new ApiError('BAD_JSON', text.slice(0, 200), res.status);
    }
  });
}

export const api = {
  getConfig: () => raw<Config>('GetConfig'),
  getAlbums: () => raw<AlbumsResponse>('GetAlbums'),
  getSongs: (album: number) => raw<SongsResponse>(`GetSongs&album=${album}`),
  getState: () => raw<AplayerState>('State'),
  play: (album: number, song: number) => raw<ResultResponse>(`Play&album=${album}&song=${song}`),
  stop: () => raw<ResultResponse>('Stop'),
  pause: () => raw<ResultResponse>('Pause'),
  next: () => raw<ResultResponse>('Next'),
  prev: () => raw<ResultResponse>('Prev'),
  seek: (percent: number) => raw<ResultResponse>(`Position&pos=${percent}`),
  setVolume: (v: number) => raw<ResultResponse>(`SetVolume&volume=${v}`),
  getPlaylists: (ind: number) => raw<PlaylistsResponse>(`GetPlaylists&ind=${ind}`),
  getPlaylist: (n: number) => raw<ResultResponse>(`GetPlaylist&playlist=${n}`),
  savePlaylist: (name: string) => raw<PlaylistsResponse>(`SavePlaylist&name=${encodeURIComponent(name)}`),
  deletePlaylist: (name: string) => raw<PlaylistsResponse>(`DeletePlaylist&name=${encodeURIComponent(name)}`),
  radioMode: () => raw<AlbumsResponse>('RadioMode'),
  getRadio: () => raw<RadioResponse>('GetRadio'),
  getPictures: () => raw<PicturesResponse>('GetPictures'),
  favor: () => raw<ResultResponse>('Favor'),
  getPath: (album: number, song: number) => raw<PathResponse>(`GetPath&album=${album}&song=${song}`),
  getImageUrl: (pl: number, image: number, cacheBust = Date.now()) =>
    `${API_BASE}/?GetImage&pl=${pl}&image=${image}&time=${cacheBust}`,
  selectCard: (card: number) => raw<unknown>(`SelectCard&card=${card}`),
  // 配置写入不要用 raw（响应是文本），见 §7.4 的 postConfig()
};
```

**注意：**

- 配置写入（`postConfig`）的 URL 是 `SetConfig`（vendor 用 `url:'SetConfig'`，不带 `?`）；实际请求为 `POST /SetConfig`。
- `raw` 对 `SetConfig` 的响应是文本 `Settings saved!`，不是 JSON；不要用 `JSON.parse`。单独实现 `postConfig` 返回文本，并让它也走同一个串行队列。
- 所有请求串行化；不要并发 `SetConfig` 和 `State`。
- 命令不自动重试。

### 5.3 错误处理映射

| 错误 | UI |
|---|---|
| `NETWORK` | 离线横幅；退避重试；不弹窗刷屏 |
| `NOT_FOUND` | “接口不存在/播放器版本不匹配”；记录诊断 |
| `HTTP_5xx` | “播放器内部错误”；显示状态码 |
| `BAD_JSON` | “响应格式异常”；记录前 200 字符 |
| `{Result:"Can't play file"}` | Toast“无法播放该文件”；保留当前状态 |
| `{Result:"..."}` 其他 | Toast 原文（先消毒） |

## 6. 状态与轮询

### 6.1 轻量 store

```ts
// src/store/store.ts
type Listener<T> = (value: T) => void;

export function createStore<T>(initial: T) {
  let value = initial;
  const listeners = new Set<Listener<T>>();
  return {
    get: () => value,
    set(next: T) {
      value = next;
      listeners.forEach((fn) => fn(value));
    },
    update(fn: (v: T) => T) { this.set(fn(value)); },
    subscribe(fn: Listener<T>) { listeners.add(fn); return () => listeners.delete(fn); },
  };
}
```

### 6.2 轮询

```ts
// src/store/player.ts
let timer: number | undefined;
let failures = 0;

async function tick() {
  try {
    const state = await api.getState();
    failures = 0;
    playerStore.set(state);
    setOnline(true);
  } catch {
    failures = Math.min(failures + 1, 3);
    setOnline(false);
  } finally {
    schedule();
  }
}

function schedule() {
  const base = document.hidden ? 5000 : 1000;
  const delay = failures ? Math.min(8000, 1000 * 2 ** failures) : base;
  timer = window.setTimeout(tick, delay);
}

export function startPolling() { stopPolling(); tick(); }
export function stopPolling() { if (timer) clearTimeout(timer); timer = undefined; }
export function refreshNow() { stopPolling(); tick(); }

document.addEventListener('visibilitychange', () => {
  if (!document.hidden) refreshNow();
});
```

- 页面隐藏时 5s；离线退避 1/2/4/8s。
- 命令成功后调用 `refreshNow()`。
- 不在轮询里重建整个视图；只更新播放条/当前视图的绑定节点。

### 6.3 进度条

- `State.Position`/`PlayingLen` 是毫秒；UI 显示 `mm:ss`/`h:mm:ss`。
- 拖动时暂停自动更新（`isDragging`）；松开后 `?Position&pos=0..100`。
- 不要在前端自行累加时间（aplayer 是权威）；轮询间隔内可用 `requestAnimationFrame` 做平滑插值，但以 State 为准。
- `ProgressVisible=false` 时隐藏进度条（电台/流）。

## 7. 配置写入（最关键）

### 7.1 规则

1. **永远不要只提交修改项。** `SetConfig` 会用请求体重建配置，未提交字段回默认值。实测只提交 `covers` 会把 668 B 配置变成 900 B 默认配置 [E6]。
2. 先 `GET ?GetConfig` 拿完整快照。
3. 从快照提取**可写字段白名单**，覆盖用户修改。
4. 前端校验类型/范围/枚举。
5. 保存上一版（localStorage + 可选 JSON 导出）。
6. `POST /SetConfig`。
7. 再次 `GET ?GetConfig`，对比关键字段；不一致则提示恢复。

### 7.2 可写字段白名单

以厂商 `SaveConfig()` 的字段集为准（详见接口文档 §5.3）。实现时建议集中在一个文件：

### 7.3 合并与校验

```ts
export function buildPayload(cfg: Config, patch: Partial<Record<WritableField, unknown>>) {
  const out: Record<string, unknown> = {};
  for (const key of WRITABLE_FIELDS) {
    out[key] = key in patch ? patch[key] : cfg[key];
  }
  return out;
}

export function validatePayload(p: Record<string, unknown>): string[] {
  const errs: string[] = [];
  const int = (k: string, min: number, max: number) => {
    const v = p[k];
    if (!Number.isInteger(v) || (v as number) < min || (v as number) > max) {
      errs.push(`${k} 必须是 ${min}..${max} 的整数`);
    }
  };
  int('pframes', 1, 1_000_000);
  int('bframes', 1, 10_000_000);
  int('num_pics', 1, 10);
  int('pt_scr', 1, 65535);
  if (typeof p.covers !== 'string' || !p.covers.trim()) errs.push('covers 不能为空');
  if (![0, 1, 2].includes(p.di_mode as number)) errs.push('di_mode 必须是 0/1/2');
  if (![0, 1, 2, 3].includes(p.dsd_limit as number)) errs.push('dsd_limit 必须是 0..3');
  return errs;
}
```

实际范围以厂商 UI 的输入约束为准（如 `std_buffer` 16384–8388608、`si_time` 等）；把范围写进字段元数据，由表单统一校验。

### 7.4 保存流程

```ts
async function saveSettings(patch: Partial<Record<WritableField, unknown>>) {
  const cfg = await api.getConfig();
  const payload = buildPayload(cfg, patch);
  const errs = validatePayload(payload);
  if (errs.length) throw new Error(errs.join('；'));

  localStorage.setItem('apui.config.previous', JSON.stringify(cfg));
  const body = await postConfig(payload); // 文本
  if (!/saved/i.test(body)) throw new Error(body);

  const after = await api.getConfig();
  for (const key of ['covers', 'root_folder', 'volume_enabled', 'dop_mode', 'pframes']) {
    if (JSON.stringify(after[key]) !== JSON.stringify(payload[key])) {
      throw new Error(`保存后校验失败: ${key}`);
    }
  }
  toast.success('设置已保存');
}
```

`postConfig` 单独实现：

```ts
export async function postConfig(payload: unknown): Promise<string> {
  const res = await fetch(`${API_BASE}/SetConfig`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(payload),
    signal: AbortSignal.timeout(8000),
  });
  const text = await res.text();
  if (!res.ok) throw new ApiError(`HTTP_${res.status}`, text, res.status);
  return text;
}
```

### 7.5 导入/导出

- 导出：`JSON.stringify(cfg, null, 2)` → Blob 下载 `apui-config-YYYYmmdd.json`。
- 导入：读取 JSON → 只取 `WRITABLE_FIELDS` → `validatePayload` → 确认 → 保存。
- 导入前保存当前配置到 `apui.config.previous`。
- 不导入 `api_key`/`api_cx`/`stat_*`。

### 7.6 声卡切换

```ts
async function selectCard(index: number) {
  if (!confirm('切换声卡会停止当前播放并重新配置音频，继续？')) return;
  await api.selectCard(index); // ?SelectCard&card=N
  // aplayer 可能停止/重启播放；等待 2s 后刷新
  setTimeout(refreshNow, 2000);

```

- `SelectCard` 只在 `config.stat_root == 1` 时可用；否则提示需要 root。
- 切换前确认；失败时显示原声卡/日志提示。
- 不要在 `.133` 上把 `SelectCard` 当作真实验收（虚拟声卡，不具代表性）。

## 8. UI 组件开发

### 8.1 安全 DOM 构建

```ts
// src/utils/dom.ts
type Props = Record<string, string | number | boolean | EventListener | undefined>;

export function el<K extends keyof HTMLElementTagNameMap>(
  tag: K,
  props: Props = {},
  children: Array<Node | string> = [],
): HTMLElementTagNameMap[K] {
  const node = document.createElement(tag);
  for (const [k, v] of Object.entries(props)) {
    if (v === undefined || v === false) continue;
    if (k.startsWith('on') && typeof v === 'function') {
      node.addEventListener(k.slice(2).toLowerCase(), v as EventListener);
    } else if (k === 'class') {
      node.className = String(v);
    } else if (k === 'text') {
      node.textContent = String(v);
    } else if (typeof v === 'boolean') {
      (node as any)[k] = v;
    } else {
      node.setAttribute(k, String(v));
    }
  }
  for (const c of children) node.append(typeof c === 'string' ? document.createTextNode(c) : c);
  return node;
}
```

- 用户数据一律 `textContent`。
- 只有 `icons.ts` 中的固定 SVG 可以用 `innerHTML`（可信常量）。
- 不拼接 HTML 字符串。

### 8.2 消毒

```ts
// src/api/sanitize.ts
export function htmlToText(html: string): string {
  const doc = new DOMParser().parseFromString(html, 'text/html');
  return (doc.body.textContent || '').replace(/\s+/g, ' ').trim();
}

export function safeUrl(raw: string, base = location.href): string | null {
  try {
    const u = new URL(raw, base);
    return u.protocol === 'http:' || u.protocol === 'https:' ? u.href : null;
  } catch {
    return null;
  }
}

export function clampInt(v: unknown, min: number, max: number, fallback: number): number {
  const n = typeof v === 'number' ? v : Number.parseInt(String(v), 10);
  return Number.isFinite(n) ? Math.min(max, Math.max(min, n)) : fallback;
}
```

### 9.1 首页

## 10. 安全开发规范

### 10.1 XSS

- 所有 aplayer 字符串（专辑名、曲目名、艺术家、电台名、播放列表名、`RadioTitle`、`conv_list`）按不可信处理。
- 禁止：

```ts
container.innerHTML = albumName;             // ❌
row.insertAdjacentHTML('beforeend', name);   // ❌
```

- 允许：

```ts
container.textContent = htmlToText(albumName); // ✅
```

- 图标 SVG 是可信常量；不要把用户数据拼进 SVG。
- 如果必须渲染富文本，使用白名单 sanitizer（DOMPurify）并限制标签/属性；默认按纯文本。

### 10.2 URL

- 电台 URL/图片 URL：只允许 `http:`/`https:`；拒绝 `javascript:`/`data:`（内置占位除外）。
- 外部图片：`referrerpolicy="no-referrer"`；`loading="lazy"`；失败占位。
- 不在 URL 中拼接未编码的名称；用 `encodeURIComponent`。

### 10.3 命令参数

- `album`/`song`：整数且在 `GetAlbums`/`GetSongs` 范围内。
- `volume`：0–100。
- `pos`：0–100。
- `ind`/`playlist`/`card`：整数且在范围内。
- `name`：非空、长度限制、无控制字符。
- 非法参数不发送；UI 显示错误。

### 10.4 敏感信息

- 不显示/不导出 `api_key`、`api_cx`。
- 不在日志/错误信息中输出完整配置。
- 配置导出仅包含可写字段（或用户明确选择完整配置时提示）。

### 10.5 部署边界

- 仅可信 LAN；无登录。
- 不把 7778 暴露到公网。
- 如需远程访问：二期伴生服务 + Basic Auth/Token + TLS，或 VPN。
- 文件浏览默认受控；不提供删除文件。

`install.sh` 要做：

1. 校验 `/opt/aplayer/aplayer` 存在。
2. 备份 `aplayer.html/js/css` + `config.dat` 到 `/opt/aplayer-ui-backup-<timestamp>/`。
3. 写 `ui/` 资源（先写临时目录，再 rename）。
4. 原子替换 `aplayer.html`（实测运行中替换即生效，无需重启 aplayer）。
5. 打印版本/备份路径/验证命令。

### 12.3 验证

```bash
curl -fsS http://127.0.0.1:7778/ | grep -q 'APUI' && echo UI_OK
curl -fsS 'http://127.0.0.1:7778/?State' >/dev/null && echo API_OK
curl -fsS -o /dev/null -w '%{http_code}\n' "http://127.0.0.1:7778/$(grep -o 'ui/app-[^"]*\.js' /opt/aplayer/aplayer.html | head -1)"
```

### 12.4 回滚

```bash
./uninstall.sh /opt/aplayer-ui-backup-20261029-120000
```

- 恢复 `aplayer.html/js/css`。
- 删除 `ui/`（或重命名为 `ui.failed-<timestamp>`）。
- 浏览器强刷。
- 不需要重启 aplayer（热替换实测生效）。

### 12.5 `.137`（OpenRC）注意

- 不新增服务；只替换文件。
- 确认 cwd：

```bash
pid=$(pgrep -f '/opt/aplayer/aplayer' | head -1)
readlink /proc/$pid/cwd
```

- 若 cwd 不是 `/opt/aplayer`，按实际路径安装，或调整 GentooPlayer 启动脚本。
- 无 systemd：不要执行 `systemctl`；用 GentooPlayer 面板/脚本重启。

### 13.2 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面 404 | `aplayer.html` 不在 cwd/被覆盖 | 检查 cwd/文件；重装 |
| 新 JS/CSS 404 | 文件名/扩展名/路径不在白名单 | 检查 `ui/`、扩展名、`check-dist` |
| 页面白屏 | JS 异常/资源 404 | DevTools Console/Network；强刷 |
| `?State` 连接重置 | aplayer 退出（音频设备缺失/崩溃） | 查 `aplayer.log`；恢复音频；重启 |
| 播放无声音 | 声卡/ALSA/音量/DSD 模式 | 设置页检查；`.137` 测试；看 `LastError` |
| 保存后配置全变 | 只提交了部分字段 | 用完整配置重存；恢复备份 |
| 封面不显示 | `pl/image` 参数/索引过期 | 重新 `GetAlbums`；检查响应 |
| 电台无图 | 远程 URL 失效/网络 | 占位；检查 URL/网络 |
| 移动端错位 | 视口/旧 CSS 缓存 | 强刷；检查 `viewport`/hash 资源 |
| `SelectCard` 失败 | 非 root/声卡不存在 | 检查 `stat_root`/`cards`；恢复 `/etc/asound.conf` |

### 13.3 日志与诊断

- aplayer：`/opt/aplayer/aplayer.log`（启动/停止/音频错误）。
- 前端：Console/Network；可选在“关于”页显示最近错误（脱敏）。
- 系统：`dmesg`（USB/ALSA）、`journalctl`（有 systemd 的机器）。
- 不在生产环境打开 verbose 轮询日志。

## 14. 代码规范

### 14.1 TypeScript

- `strict: true`；避免 `any`（接口边界可用 `unknown` + 校验）。
- 导出函数显式返回类型；公共类型放 `types.ts`。
- 不吞异常；错误分类并给出用户可读信息。
- 命令函数命名：`getXxx`/`playXxx`/`saveXxx`；不要混用。

### 14.2 CSS

- 使用 CSS 变量；不硬编码颜色（除 tokens）。
- 类名：`block__element--modifier` 或语义化短名；避免深层嵌套。
- 不使用 `!important`（除非覆盖第三方，本项目无）。
- 移动优先或桌面优先均可，但断点统一。
- 避免 `position: fixed` 过多；播放条/导航固定，其余滚动。

### 14.3 HTML

- 语义标签：`nav`/`main`/`section`/`button`。
- 按钮用 `<button type="button">`；不要用 `div onclick`。
- 表单 label 关联 input；错误信息 `aria-describedby`。
- 图片 `alt`；装饰图 `alt=""`。

### 14.4 注释

- 只写“为什么/约束”，不写“这行做什么”。
- 复杂接口/兼容性/安全约束必须注释。
- TODO 带负责人/日期/issue。

### 14.5 Git

- 分支：`main`、`feature/<name>`、`fix/<name>`、`release/<version>`。
- 提交：小而聚焦；消息说清“行为变化”。
- PR：描述、截图、测试命令、风险/回滚。
- 不提交 `work/`、`node_modules/`、构建产物（除发布包）。
